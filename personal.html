Technology

Bluetooth LE Audio, the current standard.

Kaibo builds on the latest Bluetooth LE Audio standard rather than a closed radio protocol — an open standard, and the reason many-to-many broadcasting is possible in the first place.

Broadcast, not paired

A channel is never tied to one device, so a single screen can serve as many listeners as the venue has.

Many channels, one room

Several transmitters run in the same space, each as its own channel, and the listener switches between them freely.
